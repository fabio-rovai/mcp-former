How it works

    
LLM
 │
 ▼  (MCP tool call)
mcpf-<adapter>             adapter scripts in bin/
 │
 ├─► build a CLAIM about the operation's safety
 ├─► tardygrada daemon: cmd=run, claim=...
 │      └─► VERIFIED  → unsafe, REJECT
 │      └─► ontology_gap → safe, EXECUTE
 ▼
underlying software        (only if gate passes)
    

    

      mcp-former is the introspection / wrapper layer.
      tardygrada
      is the verification engine. Two-layer model — clean separation.
