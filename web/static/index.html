Wrap any CLI behind a verification gate.

Pick a target tool, get a downloadable adapter that gates destructive operations against a domain ontology. Every block is explainable — traces back to a specific grounded fact with provenance.

Wrap any tool

Paste a built-in name (git, kubectl, gh, aws, psql) or any GitHub repo URL. Built-in names use the curated bundled ontology. URLs trigger LLM ontology generation, validated through open-ontologies.

How it works

    
LLM
 │
 ▼  (MCP tool call)
mcpf-<adapter>             adapter scripts in bin/
 │
 ├─► build a CLAIM about the operation's safety
 ├─► tardygrada daemon: cmd=run, claim=...
 │      └─► VERIFIED  → unsafe, REJECT
 │      └─► ontology_gap → safe, EXECUTE
 ▼
underlying software        (only if gate passes)
    

    

      mcp-former is the introspection / wrapper layer.
      tardygrada
      is the verification engine. Two-layer model — clean separation.
