how it works

    

      Three steps. No surprises.
    


    

      

        
01 — Download

        
Clone the repo.

        

          Shallow clone over HTTPS. Detect the binary from
          Cargo.toml, pyproject, package.json, or go.mod. No build
          required.
        

      

      

        
02 — Map

        
Extract the surface as a graph.

        

          Parse cobra Use:
          / clap / click / mitchellh-cli definitions. LLM emits an
          OWL ontology — destructive operations, protected resources,
          target classes. OWL-RL closes the hierarchy.
        

      

      

        
03 — Rebuild

        
Ship as MCP.

        

          Bundle: generic ontology-driven adapter, MCP server (JSON-RPC
          over stdio), Anthropic skill, README, AUDIT report. Drop into
          ~/.claude/mcp.json and
          your LLM calls the gated tool directly.
